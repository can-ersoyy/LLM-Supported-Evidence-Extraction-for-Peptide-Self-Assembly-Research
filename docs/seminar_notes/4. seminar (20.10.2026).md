New idea for ground truths: citation by location

In order for this to work, we need to parse full-text XML into a structured format that can distinguish between structural parts like (section, subsection, paragraph, sentence) and special constructs like (image, table etc.)
We could build a tree out of these

```python
class Node():
	self.id
	self.children
	self.parent_id
	self.content

class RootNode(Node)
class SectionNode(Node)
class ParagraphNode(Node)
class SentenceNode(Node)

# and specials (these will have additional fields and logic)
class ImageNode(Node)
class TableNode(Node)

def parse_xml(fulltext_body: string) -> Node # returns the RootNode after creating a tree out of fulltext
def to_debug_string(root_node: RootNode) -> string
def to_llm_string(root_node: RootNode) -> string
def validate_field(loc: string, value: string) -> bool # this will require tree traversal mechanism
```

We will start with JATS XML files first since there is much more data available
Image and table nodes are low prio
PDF to XML (using grobid) is low prio -> requires different parse_xml

We need lots of unit tests

After implemented, we can run the extraction on 10 golden dataset papers and compare the results with the previous method on groundness_rate -> this would need to have a new method that uses validate_field and a judge llm here as well

#### Benefit of using a tree structure
- Enables sections to be cleanly seperated, which allows for new use cases: passing only sections to llm, working easier with images/tables, evaluation of images/tables
- A clean interface on different types of text (XML and PDF). Now they will all return the same format (Node tree) -> more reliable extraction
