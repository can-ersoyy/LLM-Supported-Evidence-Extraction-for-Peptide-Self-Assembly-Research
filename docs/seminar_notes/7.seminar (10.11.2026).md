## Query for Relevance Comparison (gemini vs gemma on 10k ncbi v3)

```sql
WITH query_a AS (
    SELECT paper_id, is_relevant, confidence
    FROM paper_relevance
    WHERE run_identifier == 1794172092 or run_identifier == 1794235032
),
query_b AS (
    SELECT paper_id, is_relevant, confidence
    FROM paper_relevance
    WHERE run_identifier == 1793467950 or run_identifier == 1793532712
)
SELECT 
    COALESCE(a.paper_id, b.paper_id) AS paper_id,
    
    -- Table A attributes
    a.is_relevant      AS gemini_relevant,
    a.confidence        AS gemini_confidence,
    
    -- Table B attributes
    b.is_relevant   AS gemma_relevant,
    b.confidence AS gemma_confidence

FROM query_a a
INNER JOIN query_b b
    ON a.paper_id = b.paper_id
where a.is_relevant <> b.is_relevant
AND a.is_relevant is not null
AND b.is_relevant is not null
ORDER BY paper_id;
```
